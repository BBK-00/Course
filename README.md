# Интерактивті сабақтар — Бақытжанов Бекет Қайратұлы

Пәндер бойынша интерактивті сабақтар жинағы. Қазір дайын: **Сандық әдістер → 5-тақырып: Алгебралық сызықтық теңдеулер жүйесін шешудің тура әдістері (Гаусс әдісі)**.

```
index.html                    басты бет
sandyq-adister/index.html     «Сандық әдістер» пәні: 15 тақырып
sandyq-adister/05-gauss.html  5-тақырып: Гаусс әдісі
sandyq-adister/06-gauss-seidel.html  6-тақырып: Гаусс–Зейдель әдісі
assets/lesson.css, lesson-core.js, work.js  жаңа тақырыптарға ортақ стиль мен модульдер
assets/                       ортақ стиль және config.js
apps-script/Code.gs           жұмыстарды қабылдап, ЖИ арқылы бағалайтын код (Google Apps Script)
```

## 1. Сайтты GitHub Pages-ке шығару

1. GitHub-та жаңа репозиторий аш (мысалы, `sabaqtar`), оны **Public** ет.
2. Осы папкадағы файлдарды репозиторийге жүкте.
3. **Settings → Pages → Build and deployment → Source: Deploy from a branch**, тармақ: `main`, папка: `/ (root)` → **Save**.
4. 1–2 минуттан кейін сайт мына мекенжайда ашылады: `https://<github-атың>.github.io/sabaqtar/`.

## 2. Жұмыстарды қабылдау және ЖИ бағалауы (бір рет, ≈10 минут)

1. Google Drive-та жаңа **Google Sheets** кестесін аш (мысалы, «Бақылау жұмыстары»).
2. Мәзірден **Кеңейтімдер → Apps Script** бөлімін аш. Ондағы кодты өшіріп, `apps-script/Code.gs` файлының мазмұнын түгел қой да, сақта.
3. Сол жақтағы **⚙ Project Settings → Script Properties → Add script property**:
   - `GEMINI_API_KEY` — Google AI Studio-дағы кілтің.
   - `GEMINI_MODEL` — міндетті емес (әдепкісі `gemini-flash-latest`).
4. **Deploy → New deployment → ⚙ → Web app**:
   - *Execute as:* **Me**
   - *Who has access:* **Anyone**
   → **Deploy**, рұқсаттарды бер. **Web app URL** сілтемесін көшір.
5. `assets/config.js` файлындағы `submitUrl: ''` жолына сол сілтемені қой да, GitHub-қа қайта жүкте:
   ```js
   submitUrl: 'https://script.google.com/macros/s/.../exec'
   ```
6. Тексеру: Web app URL-ды браузерде ашсаң, «Жұмыс қабылдау қызметі істеп тұр.» деген жазу шығуы керек.

> **Маңызды:** Gemini кілтін ешқашан сайт файлдарына немесе GitHub-қа жазба. Ол тек Apps Script-тің Script Properties бөлімінде сақталады. Кілт жария болып қалса, Google AI Studio-да оны өшіріп, жаңасын жаса.

## Кестедегі парақтар

- **Журнал** — тек балл: әр студент бір жолда, әр тақырып бөлек бағанда (90+ жасыл, 75–89 ашық жасыл, 60–74 сары, 60-тан төмен қызғылт). Журналға көшіруге ыңғайлы.
- **Талдау** — әр жұмыстың толық мәліметі: бөліктер бойынша балл, ЖИ үлесі, белгілері, түсініктеме, шешу барысы мен код.
- **«Бағалау» мәзірі:** ЖИ бағаламаған жолдарды қайта бағалау; журналды «Талдау» парағынан қайта құру.

## Бағалау (100 балл = қатысым 40 + тапсырма 60)

| Бөлік | Кім тексереді | Балл |
|---|---|---|
| Қатысым (жұмыс тапсырылса) | Скрипт | 40 |
| Тест (6 сұрақ) | Скрипт | 12 |
| Қолмен жауаптар (3 сан) | Скрипт | 9 |
| Шешу барысы | ЖИ | 15 |
| Бағдарлама нәтижесі | Скрипт | 6 |
| Бағдарлама коды (кез келген тіл) | ЖИ | 18 |

**Жалпы балл = 40 + тапсырма сапасы × коэффициент.** ЖИ үлесі 30%-ға дейін болса, коэффициент 1; 90% болса, 0,2. Балл 50-ден төмен түспейді. 6-тақырыпта балл тапсырған соң студенттің экранына шығады.

## Live сабақ жүйесі (6-тақырып және одан кейінгілер): Cloudflare Worker + D1

5-тақырып бұрынғыдай Google Sheets/Apps Script арқылы жұмыс істейді. 6-тақырыптан бастап барлығы сайттың өзінде: `src/` ішіндегі Worker (API) және D1 базасы. Excel қажет емес.

**Бір рет баптау (≈10 минут):**
1. Cloudflare → Storage & databases → D1 → **Create database** (атауы `bbk-courses-db`). `database_id` мәнін көшіріп, `wrangler.jsonc` ішіндегі `REPLACE_WITH_D1_DATABASE_ID` орнына жазыңыз.
2. Cloudflare → Workers → `bbk-courses` → Settings → **Variables and Secrets**: екі құпия мән қосыңыз (Type: Secret):
   - `TEACHER_PASSWORD` — оқытушы панеліне кіру құпиясөзі;
   - `GEMINI_API_KEY` — Gemini кілті.
3. GitHub-тағы `main` өзгерсе, Cloudflare сайтты өзі жаңартады. Кестелер бірінші сұраныста өзі жасалады, қолмен миграция қажет емес.

**Қолдану:**
- Оқытушы: `/teacher/` → құпиясөз → «Топтар мен студенттер» (топ қосу, аттарды тізіммен қою) → «Сабақ» → «Сабақты бастау» (4 таңбалы код) → студенттер кіргеннен кейін «Жұмысты бастау» (40 мин).
- Студент: сабақ бетінде «Сабаққа кіру» → топ, аты, код. Қатысым (40 балл) автоматты түседі, аты бір құрылғыға бекітіледі (оқытушы 📱 батырмасымен босатады).
- Әр тапсырма жеке жіберіледі және бірден бағаланады. Оқытушы панелінде ЖИ талдауын көріп, әр тапсырма мен қорытынды баллды түзетеді. «Журнал» бөлімі студент × тақырып кестесін көрсетеді (көшіруге болады).

**Жергілікті тест:** `npm install`, `.dev.vars` ішіне `TEACHER_PASSWORD=test123` және `GEMINI_STUB=1` жазып, `node scripts/devsite.mjs`, `npx wrangler dev -c wrangler.dev.jsonc --port 8787 --local`, содан кейін `node test/api.test.mjs`.
