# Интерактивті сабақтар — Бақытжанов Бекет Қайратұлы

Пәндер бойынша интерактивті сабақтар жинағы. Қазір дайын: **Сандық әдістер → 5-тақырып: Алгебралық сызықтық теңдеулер жүйесін шешудің тура әдістері (Гаусс әдісі)**.

```
index.html                    басты бет
sandyq-adister/index.html     «Сандық әдістер» пәні: 15 тақырып
sandyq-adister/05-gauss.html  5-тақырып: сабақ + бақылау жұмысы
assets/                       ортақ стиль және config.js
apps-script/Code.gs           жұмыстарды қабылдап, ЖИ арқылы бағалайтын код (Google Apps Script)
```

## 1. Сайтты GitHub Pages-ке шығару

1. GitHub-та жаңа репозиторий аш (мысалы, `sabaqtar`), оны **Public** ет.
2. Осы папкадағы файлдарды репозиторийге жүкте.
3. **Settings → Pages → Build and deployment → Source: Deploy from a branch**, тармақ: `main`, папка: `/ (root)` → **Save**.
4. 1–2 минуттан кейін сайт мына мекенжайда ашылады: `https://<github-атың>.github.io/sabaqtar/`.

## 2. Жұмыстарды қабылдау және ЖИ бағалауы (бір рет, ≈10 минут)

1. Google Drive-та жаңа **Google Sheets** кестесін аш (мысалы, «Бақылау жұмыстары»).
2. Мәзірден **Кеңейтімдер → Apps Script** бөлімін аш. Ондағы кодты өшіріп, `apps-script/Code.gs` файлының мазмұнын түгел қой да, сақта.
3. Сол жақтағы **⚙ Project Settings → Script Properties → Add script property**:
   - `GEMINI_API_KEY` — Google AI Studio-дағы кілтің.
   - `GEMINI_MODEL` — міндетті емес (әдепкісі `gemini-flash-latest`).
4. **Deploy → New deployment → ⚙ → Web app**:
   - *Execute as:* **Me**
   - *Who has access:* **Anyone**
   → **Deploy**, рұқсаттарды бер. **Web app URL** сілтемесін көшір.
5. `assets/config.js` файлындағы `submitUrl: ''` жолына сол сілтемені қой да, GitHub-қа қайта жүкте:
   ```js
   submitUrl: 'https://script.google.com/macros/s/.../exec'
   ```
6. Тексеру: Web app URL-ды браузерде ашсаң, «Жұмыс қабылдау қызметі істеп тұр.» деген жазу шығуы керек.

> **Маңызды:** Gemini кілтін ешқашан сайт файлдарына немесе GitHub-қа жазба. Ол тек Apps Script-тің Script Properties бөлімінде сақталады. Кілт жария болып қалса, Google AI Studio-да оны өшіріп, жаңасын жаса.

## Бағалау (100 балл)

| Бөлік | Кім тексереді | Балл |
|---|---|---|
| Тест (6 сұрақ) | Скрипт | 20 |
| x, y, z жауаптары | Скрипт | 15 |
| Шешу барысы | ЖИ | 25 |
| Python нәтижесі | Скрипт | 10 |
| Python коды | ЖИ | 30 |
| ЖИ қолданғаны үшін айыппұл | ЖИ | 0…−50 |

ЖИ көшіріп қою санын, теру көлемін, жұмсалған уақытты, беттен шығу санын және жұмыстың стилін ескереді. Күдігі 60%-дан жоғары жұмыстың жолы кестеде қызылмен белгіленеді. ЖИ-ді анықтау 100% дәл емес, сондықтан қызыл жолдарды оқытушы өзі қарап шыққаны дұрыс. ЖИ бағалай алмаса, жалпы балл бос қалады да, түсініктемеде «қолмен бағалаңыз» деп жазылады.
