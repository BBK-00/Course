# Кино куиз: керек клиптер

Ойын `quiz/data/kino.json` ішінде дайын, дауысы жасалған. 1-кезең мен 3-кезеңге **10 қысқа видео** керек.
Клипті таппаса, ойнатқыш «🎬 Клип қосылмаған» деп файл атын көрсетеді.

**Құқық ескертуі.** Фильм үзінділері авторлық құқықпен қорғалған. Оларды тек сыныпта көрсету үшін, жеке пайдаланыңыз.
Ашық интернет-репоға (`main`) мұндай файлдарды салмаңыз: сайт ашық, файл автоматты түрде жарияланады.

## Файл талаптары
- Пішімі: **MP4** (H.264 + AAC), 1280×720 не одан кіші.
- Ұзақтығы: **5–10 секунд**, көлемі **3 МБ-тан аз**.
- Орналасуы: `quiz/media/kino/` қалтасы, файл аттары төменде.
- Кесу мысалы (ffmpeg): `ffmpeg -ss 00:12:30 -i film.mkv -t 8 -c:v libx264 -c:a aac -vf scale=1280:-2 r1-1.mp4`
