# «Ән мен әнші 2»: керек әндер

Ойын `quiz/data/ani2.json` ішінде дайын, жүргізуші дауысы жасалған. 1-кезеңге **5 ән үзіндісі** керек (8–10 секунд).
Файл жоқ болса, ойнатқыш «🎬 Клип қосылмаған» деп файл атын көрсетеді.

**Құқық ескертуі.** Нақты әндер авторлық құқықпен қорғалған, мен оларды қоса алмаймын. Файлдарды сыныпта көрсету үшін жеке пайдаланыңыз.
Quiz бөлімі қазір ашық сайттан жасырылған (`.assetsignore`), сондықтан файлдар интернетке жарияланбайды. Ашар алдында бұл туралы қайта ойланыңыз.

## Файл талаптары
- Пішімі: **MP3**, 8–10 секунд, көлемі 500 КБ-тан аз.
- Орналасуы: `quiz/media/ani2/`, аттары төменде.
- Кесу мысалы (ffmpeg): `ffmpeg -ss 00:00:30 -i ән.mp3 -t 9 -c:a libmp3lame -b:a 128k r1-1.mp3`
- Әннің атауы айтылмайтын, бірақ танылатын жерін таңдаңыз.

| Файл | Ән | Орындаушы |
|---|---|---|
| r1-1.mp3 | Ауырмайды жүрек | Қайрат Нұртас |
| r1-2.mp3 | Ақпен бірге | Молданазар |
| r1-3.mp3 | Blinding Lights | The Weeknd |
| r1-4.mp3 | Крошка моя | Руки Вверх! |
| r1-5.mp3 | Gangnam Style | PSY |

`ring.wav` (телефон қоңырауы) өзім синтездедім, қосу керек емес.

## Тексеру керек
- 3-кезеңнің 2-сұрағы («Ана туралы жыр»): жалғасын («Сыйладың сен маған») түпнұсқа мәтінмен салыстырып тексеріңіз, мен растай алмадым.
