if шарты операторы

Тармақталған алгоритмдер. Бағдарлама шешімді осылай қабылдайды.

1if операторын жазуды үйренесің.
2Салыстыру амалдарын қолданасың.
3Кірістірілген шарттарды жазасың.
4Кодтағы қатені табасың.

1if қалай жұмыс істейді

Бұл бөлімде бағдарламаның шешім қабылдау жолын қадам-қадаммен көресің. Бағдарлама жолдарды ретімен орындайды. if оператор шартты тексереді: шарт True (ақиқат) болса ғана, ішіндегі жолдар орындалады. Шарт False (жалған) болса, олар өткізіліп кетеді. Мысалы: «жауын жауса, қолшатыр аламын».

2if қалай жазылады

Бұл бөлімде if жолының төрт бөлігін үйренесің. Бөлікті басып, оның қызметін оқы.

3Салыстыру амалдары

Бұл бөлімде шартта қолданылатын алты таңбаны үйренесің. Әр салыстыру True немесе False нәтиже береді. Мысалын көру үшін карточканы бас.

4Мысалдар: өзің сынап көр

Бұл бөлімде үш мысалды орындап көресің. Санды өзгертсең, қай жолдың орындалғаны бірден көрінеді. Үшінші мысалда кірістірілген if бар: екінші шарт тек бірінші шарт True болғанда тексеріледі.

5Жиі кететін қателер

Бұл бөлімде төрт жиі қатені және оның түзетілуін көресің. Дұрыс нұсқасын көру үшін карточканы бас. Тапсырмада осындай қателерді өзің табасың.
