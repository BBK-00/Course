for циклі және range()

Бір әрекетті бірнеше рет орындау үшін цикл жазамыз. Блок-схемамен әр қадамды бақылап, Python циклді қалай жүргізетінін көр.

Бірінші мысалды ашу ↓
range(1, 6)

01

Цикл қалай қайталанады?

Цикл — бір әрекетті бірнеше рет орындайтын құрылым.

Циклсіз 
print("Сәлем")
print("Сәлем")
print("Сәлем")
print("Сәлем")
print("Сәлем")
5 рет жазу үшін 5 жол керек. 100 рет керек болса, 100 жол жазасың.
Циклмен 
for i in range(5):
    print("Сәлем")
Қанша рет қайталанса да, жол саны өзгермейді: тек 5 саны ауысады.
for i in range(1, 6):
    print(i)
  • for — «әр сан үшін» деген мағына, цикл осыдан басталады.
  • i — айнымалы. Әр қайталауда қатардағы келесі санды алады.
  • range(1, 6) — сандар қатары: 1, 2, 3, 4, 5.
  • : — қос нүкте. Мұнан кейін цикл денесі басталады.
  • 4 бос орын — цикл денесі. Тек осы жолдар қайталанады.
Есептің шарты

1-ден 5-ке дейінгі бүтін сандарды 5-ті қоса, әрқайсын жеке жолға шығар.

Күтілетін нәтиже: 1, 2, 3, 4, 5. Әр сан жаңа жолдан шығады.

Қалай қарау керек. Блок-схемада жанып тұрған блок — Python қазір орындап жатқан қадам. Сол қадамның коды да жанады. «Қадам» — бір әрекет, «Келесі сан» — келесі қайталаудың басына өту, «Ойнату» — өздігінен жүру.

Есіңде болсын. Python әр қайталау алдында сұрайды: «Қатарда сан қалды ма?». Иә болса, келесі санды i айнымалысына беріп, цикл денесін орындайды да, сұраққа қайта оралады. Жоқ болса, циклді тастап, одан кейінгі жолға өтеді.

02

range() қандай сандар береді?

Цикл қай сандармен жүретінін range() айтады. Жазылуының үш түрі бар.

range(5)Тек шекара

0-ден бастап, қадам 1. Сандар: 0, 1, 2, 3, 4.

range(1, 6)Бастау және шекара

1-ден бастап, қадам 1. Сандар: 1, 2, 3, 4, 5.

range(2, 10, 2)Қадаммен

2-ден бастап, әр жолы +2. Сандар: 2, 4, 6, 8.

  • Шекара (stop) кірмейді. Қадам 1 болып, бастау шекарадан кіші болса, санын шекарадан бастауды азайтып табасың. range(1, 6) бес сан береді.
  • Қадам оң болса, сандар өседі. Қадам теріс болса, сандар кемиді, сонда бастау шекарадан үлкен болуы керек.
  • Қадамның бағыты сәйкес келмесе, қатар бос болады. Мысалы, range(2, 8, -1) еш сан бермейді.
  • Қадам 0 бола алмайды, Python қате береді.
03

Жинақтаушы қорап

Үш мысалдың бірін таңда. Айнымалының бастапқы мәніне және әр қадамда қалай өзгеретініне қара.

Санауыш циклдің неше рет қайталанғанын санайды.

Есептің шарты

1-ден n-ге дейінгі сандардың неше екенін тап. Нәтижені экранға шығар.

Мысал: n = 5 болса, санауыш 5.

Қалай жұмыс істейді. Санауыш k = 0-ден басталады. Әр қайталауда k = k + 1 орындалады: сан қандай болса да, санауышқа тек 1 қосылады. Сондықтан нәтиже сандардың мәніне емес, олардың санына тең.

Қосынды әр санның мәнін қосып жинайды.

Есептің шарты

1-ден n-ге дейінгі сандардың қосындысын тап. Нәтижені экранға шығар.

Мысал: n = 5 болса, қосынды 15.

Қалай жұмыс істейді. Қосынды s = 0-ден басталады: қорап алғашында бос. Әр қайталауда s = s + i орындалады, яғни қорапқа сол кезеңдегі сан қосылады. Санауыштан айырмасы: 1 емес, i қосылады.

Көбейтінді әр санды көбейтіп жинайды.

Есептің шарты

1-ден n-ге дейінгі сандардың көбейтіндісін тап. Нәтижені экранға шығар.

Мысал: n = 5 болса, көбейтінді 120.

Қалай жұмыс істейді. Көбейтінді p = 1-ден басталады, 0-ден емес: 0-ге көбейткен кез келген сан 0 болып қалар еді. Әр қайталауда p = p * i орындалады. Мысалы, 1 × 2 × 3 × 4 × 5 = 120.

04

Цикл ішіндегі if

Цикл әр санды береді, ал if сол санды тексереді. Шарт ақиқат болғанда ғана if денесі орындалады.

if-сіз 
for i in range(1, 11):
    print(i)
Экранға 1-ден 10-ға дейінгі барлық сан шығады.
if-пен 
for i in range(1, 11):
    if i % 3 == 0:
        print(i)
Тек шартқа сай сандар шығады: 3, 6, 9. Қалғандары өткізіліп кетеді.
for i in range(1, 11):
    if i % 3 == 0:
        print(i)
  • for — әр қайталауда келесі санды i айнымалысына береді.
  • i % 3 == 0 — шарт. % бөлгендегі қалдықты табады. Қалдық 0 болса, сан 3-ке қалдықсыз бөлінеді.
  • 8 бос орын — if денесі. Ол тек шарт ақиқат болғанда орындалады. Екінші шегініс осыны көрсетеді.
Есептің шарты

Мысалда сандарды өзің таңда: шартты, соңғы санды және не істейтінін ауыстыр. Әр сан үшін Python шартты қалай тексеретінін қадаммен қара.

Бұл жерде әр түрлі шарт көрсетіледі. Тапсырмада басқа шарттар мен сандар болады, сондықтан ойланып, өзгертіп жазу керек.

Есіңде болсын. Санауыш пен қосынды if ішінде өзгереді: тек шартқа сай сан есепке қосылады. Ал k = 0 және s = 0 циклден бұрын, ал нәтижені шығаратын print циклден кейін (шегіністерсіз) жазылады.

05

Жиі қателер

Қате кодты көр, Python не істейтінін оқы, сосын түзет.

Тапсырмалар

Әр тапсырманы оқытушы бастайды. Бастамай тұрып жіберуге болмайды. Уақыт бітсе, жауап қабылданбайды.

  1. 1 · Қарапайым есептер15 минут · 20 балл
  2. 2 · Қосынды және көбейтінді20 минут · 30 балл
  3. 3 · Цикл және шарт15 минут · 30 балл
  4. 4 · Аралас тест10 минут · 20 балл

Тапсырма жіберу үшін жоғарыдағы «Сабаққа кіру» батырмасымен кір.

Қатемен жұмыс. Әр тапсырма біткен соң оқытушы сол тапсырманың қатемен жұмысын ашады. Қате есепті түзетіп қайта жіберсең, жоғалтқан баллдың 70%-ы қайтады, 30%-ы ұсталады. Кодқа 3 әрекет, тестке 1 әрекет беріледі. Уақытында жібере алмаған есепті де қатемен жұмыс кезінде жіберуге болады, бірақ оған ең көбі 70% (тестте 50%) беріледі. Қатемен жұмыс сол тапсырманың өз ішінде шығады. Оқытушы бір уақытта екі тапсырманы ашып, уақытын ұзарта алады.
