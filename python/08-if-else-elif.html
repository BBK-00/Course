if–else және elif

Толық тармақталу. Бағдарлама екіден көп жолдың біреуін таңдайды.

1if–else операторын жазуды үйренесің.
2elif арқылы бірнеше шартты тексересің.
3Кодтағы қатені табасың.

1Бағдарлама қалай шешім қабылдайды

Бұл бөлімде бағдарламаның жолды қалай таңдайтынын көресің. if шарт ақиқат болғанда ғана жұмыс істейді. else («әйтпесе») шарт жалған болғанда орындалады. elif («әйтпесе егер») келесі шартты тексереді. Python шарттарды жоғарыдан төмен қарай тексереді және бірінші True шартта тоқтайды. Мәнді өзгертіп, жолдың қалай өзгеретінін көр.

2Жазылу ережесі

Бұл бөлімде үш конструцияның жазылуын көресің. Төмендегі батырманы бассаң, сәйкес бөлік кодта боялады.

3Қатені тап

Бұл бөлімде бес қате кодты түзетесің. Терминалдағы нәтижеге қарап, қате жолды бас. Дұрыс болса, жол түзетіледі және түсініктеме шығады.
