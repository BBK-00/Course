# Оқытушы панелі

Жаңа панель бұрынғы сабақ, тапсырма, баға және қатысым кестелерін қолданады. Дизайн жаңартуы дерекқорды көшірмейді, тазаламайды және бағаларды қайта есептемейді.

## Файлдар

- `index.html` — кіру экраны, мәзір, бөлімдер және диалогтар.
- `dashboard.css` — жаңа бейімделетін көрініс. Сабақ беттеріне әсер етпейді.
- `panel-base.css` — бұрынғы тапсырма тексеруі, жоспар, жұптық жұмыс және басқа құралдардың негізгі стильдері.
- `lesson-catalog.js` — пәндер, тақырыптар, тапсырма атаулары/салмақтары, уақыттар мен бекіту сұрақтары. Жаңа сабақтың оқытушыға көрінетін сипаттамасын осы жерге қосу керек. Нақты бағалау серверде қалады.
- `archive.js` — сабақтарды іздеу, сүзу, таңдау, өшіру және қалпына келтіру. Басқа панель бөлімдерінен бөлек модуль.
- `panel.js` — API, жаңарту, сабақ барысы, талдау, журнал, топтар, архив және студент жұмысы терезесі.

## Қолдану

Негізгі мәзір: Сабақ / Үй жұмысы / Журнал / Топтар / Архив.

Сабақ қойындылары: Барысы / Талдау / Бекіту / Жоспар. Қойынды ауысқанда сол сабақ контексті сақталады. Пән/тақырып/топты ауыстыру сақталған сабақты ашады немесе жаңа сабақты бастау формасын көрсетеді; өзі сабақ бастамайды.

«Топтар» бөліміндегі таңдалған топта «Сабақ бастау» батырмасы бар; ол топты алдын ала таңдайды. Жаңа топ, атау және белсенді студент саны ашық бастау формаларында бірден жаңарады. Форманың пән/тақырып/топ таңдауы қайта ашқанда сақталады. Топты жою кезінде жарамсыз қалған таңдаудың орнына басқа топ өздігінен таңдалмайды.

Бастау сәтті аяқталса, архив контексті тазаланып, панель жаңа сабаққа өтеді. Қайталанған басу қосымша сабақ ашпайды. Бастау қатесінде форма мен таңдау сақталады. Сабақ серверде басталып, кейінгі жүктеу үзілсе, ескі сабақтың басқаруы жасырылып, қайта жүктеу ұсынылады; бұл жаңа сабақ құрмайды.

P4 кезеңдері жеке басқарылады. Келесі кезеңді бастарда алдыңғы кезеңді аяқтау сұралады. Басқа сабақтар бұрынғы ортақ таймерімен жұмыс істейді. P8 жұптары бөлек ашылатын аймақта.

Студенттер беттелмейді: бір топ бір тізімде. Жаңарту кестенің өзгерген жолдарын ғана ауыстырады. Іздеу, фокус, кестенің айналдыру орны және ашық бағалау терезесі сақталады. Бағаны сақтау қатесі сәтті сақтау ретінде көрсетілмейді. Басқа өрістегі сақталмаған өзгерістер бір тапсырманы сақтағанда жоғалмайды.

`Қайта орындату` — бұрынғы тазалау әрекеті; оған бөлек растау керек. Кезеңді немесе сабақты `Қайта ашу` бұрынғы жауаптарды сақтайды.

Архивте қатысушысыз сабақтар да көрінеді. Пән/топ/күн/күй сүзгісі және бірнеше сабақты таңдау бар. Сүзгі өзгерсе, жасырын таңдау қалмайды. Өшіруге дейін нақты сабақтар мен сақталған тапсырма саны көрсетіледі. Жүріп жатқан сабақты өшіруге болмайды.

Өшіру сабақты `session_trash` кестесінде белгілейді. Қатысым, баға, пікір, фото, жауаптар мен код кестелері өзгермейді. Өшірілген сабақ журналдан, сабақ таңдауынан және үй жұмысы тізімінен алынады. «Өшірілгендер» бөлімінде жеке/бірнешеуін қалпына келтіруге болады. Қалпына келтіру сабақты өздігінен ашпайды, басқа сабаққа әсер етпейді. Автоматты не біржола тазалау жоқ.

«Үй жұмысы» бөлімінде ЖИ тексеріп жатқан және қате себепті қайта тексерілетін фотолар да көрінеді. Бағасы әлі болмаса, «Балл күтілуде» деп көрсетіледі. Фото жұмыс терезесінде ашылады. ЖИ қателері бағаланған 3 әрекетке кірмейді. Іске асыру мен тексеру: `HOMEWORK-AI.md`.

Бір тақырып қайталанса, журнал ең жақсы нәтижені көрсетеді (тең болса, соңғы сабақ). Өшірілген сабақ есепке кірмейді. Қалпына келгенде сол нәтиже қайта есепке алынады.

## Тексеру

Қолданбаны жоба түбірінен іске қосу керек:

```powershell
node scripts/devsite.mjs
npx wrangler dev -c wrangler.dev.jsonc --port 8788 --local --persist-to .wrangler/dashboard-qa
```

Бөлек терминалда:

```powershell
$env:BASE='http://127.0.0.1:8788'
node test/py4.api.test.mjs
node test/dashboard.api.test.mjs
node test/archive.api.test.mjs
node test/py8.api.test.mjs
node test/api.test.mjs
```

Тесттер тек оқшауланған жергілікті базаға арналған: топ, студент, сабақ жасайды және жабады. `dashboard.api.test.mjs` алдында P4 API тесті орындалуы керек. Ол баға, пікір, фото және бастапқы жауаптардың панельді қарағаннан кейін өзгермегенін салыстырады.

`archive.api.test.mjs` жеке деректерін жасайды; фото тексеруі үшін жергілікті Gemini stub қажет. Бос сабақ, токенсіз тыйым, қате/аралас топтық сұраныстың жартылай орындалмауы, ашық сабақ қорғанысы, журналдың келесі ең жақсы бағаға ауысуы және толық қалпына келуі тексеріледі. Жаңа кесте нақты базаның көшірмесіне де тексерілді: бұрынғы кестелердің барлық жолдары өзгеріссіз қалды.

Браузерде қосымша тексерілген: 24 студенттік үздіксіз тізім, жеке кезеңді бастау, талдау сүзгілері, іздеу/фокус сақтау, желі қатесінде баға өрістерін сақтау, сақталмаған өзгерісті жабуды тоқтату, 320/390px мәзірі және кесте ішіндегі айналдыру.

`test/teacher-start.browser.js` ішіндегі `teacherStartBrowserTest` функциясы тек жергілікті браузерде орындалады (`127.0.0.1`/`localhost` қорғанысы бар). Ол шынайы интерфейспен топ құрады, студент қосады, топтан және негізгі формадан сабақ бастайды. 23 тексеру: тізімнің жаңаруы, таңдау сақтау, батырманың толық мәтіні, бос топ, желі қатесі, архив контексті, екі рет басу, сабақтан кейін студент қосу және жүктеуді қайталағанда сабақтың қайталанбауы. Компьютерде және 320/390px-де тексерілген.
